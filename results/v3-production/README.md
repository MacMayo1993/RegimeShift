# Production results

One complete run of the manuscript's Table 2 design, committed so the numbers
can be read, re-analysed and cited without re-running the grid.

312 configurations, 936 detector rows, 468,000 simulated two-segment datasets,
base seed 20260713. Regenerate with:

```bash
python -m regimeshift run --grid production --out results/v3-production --workers 4
```

| File | Contents |
|---|---|
| `run_manifest.json` | commit, environment, package versions, timing, and a SHA-256 for every file below |
| `full_results.csv` | every detector-level result row |
| `score_regression_summary.csv` | raw-score regression coefficients against predictions, OLS and WLS |
| `crossover_estimates.csv` | estimated 50%-power crossover lengths |
| `crossover_ratio_summary.csv` | median practical sample-length ratios |
| `crossover_bootstrap.csv` | bootstrap intervals for the crossover lengths |
| `crossover_ratio_bootstrap.csv` | bootstrap intervals for the median ratios |

`tests/test_committed_results.py` verifies every file against its recorded
checksum, so a hand-edited CSV is detectable. Those tests skip when this
directory is absent.

To re-report in bits, as multiples of `K* = 1/(2 ln 2)`:

```bash
python -m regimeshift analyse --results results/v3-production/full_results.csv \
                              --out results/v3-production-bits --units bits
```

## Reading these files

`docs/paper-notes.md` compares the regression summary against the manuscript's
Tables 3-6 cell by cell, and flags the one place they disagree: the `m = 5`
full-model slope, which the manuscript reports as 2.119 and discusses as a real
finite-sample deviation, comes out at 1.967 here.

The `higher_mode` rows of `crossover_ratio_summary.csv` should be ignored. Under
that scenario the constrained detectors barely reach 50% power inside the grid,
so only one effect produces an internal crossover and the resulting ratios
divide near-noise by near-noise. The `_n` columns record how many effects backed
each median.

The manifest records `dirty: true`: the run was launched with this README
uncommitted. The commit it names is the infrastructure commit and no code
differed.

**Scope.** These are simulated data generated by the models under test. No real
dataset is analysed anywhere in this repository.
