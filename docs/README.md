# Documents

* `Geometric_Complexity_Cyclic_Regime_Changes_v3_1.docx` — the manuscript,
  version 3.1 (Mac Mayo, July 2026).
* `paper-notes.md` — what the code reproduces exactly, which constants had to be
  reconstructed because the source rendered them as images, and what is
  deliberately out of scope.

The manuscript's "Code and data availability" section names the files of the
original production run. This repository reorganises the same functionality:

| Manuscript file | Here |
|---|---|
| `mayo_cyclic_detectors_v3.py` | `regimeshift/fourier.py`, `regimeshift/detectors.py`, `regimeshift/gains.py` |
| `v3_simulation.py` | `regimeshift/scenarios.py`, `regimeshift/simulation.py` |
| `run_v3_full_parallel.py` | `regimeshift/runner.py`, `regimeshift/cli.py` |
| `test_mayo_cyclic_detectors_v3.py` | `tests/` (structural suite, plus statistical validation) |
| `v3_full_results.csv` | `full_results.csv` written by `regimeshift run` |
| `v3_score_regression_summary.csv` | `score_regression_summary.csv` |
| `v3_crossover_estimates.csv` | `crossover_estimates.csv` |
| `v3_crossover_ratio_summary.csv` | `crossover_ratio_summary.csv` |

The result CSVs are not committed — they are regenerated by
`python -m regimeshift run --grid production --workers 16`, which is
deterministic given base seed 20260713.
